# MoMo Merchant Success · Insight Hub

An interactive analytics dashboard designed to translate raw merchant call transcripts into actionable product, operations, and customer success insights.

## 🌟 Key Features

- **Merchant Voice Signals & Dynamic Word Cloud**: Aggregates word frequencies from call transcripts across customizable date ranges using `WordCloud2.js`.
- **Sentiment & Attitude Stream**: Analyzes call directionality (Positive, Negative, Neutral) to monitor overall merchant experience trends.
- **Merchant Persona & Anxiety Matrix**: Categorizes core merchant friction points, including fraud concerns, age/technology barriers, and reliance on relatives.
- **Monthly Interactive Analytics**: Tracks call volume metrics and primary focus messages month-by-month using `Chart.js`.
- **Campaign Lookup System**: Dynamic search and topic-based filtering for active outreach and care campaigns.
- **Audio Transcript Simulator**: Embedded interactive player simulating merchant call excerpts and real-world quotes.
- **Neo-Brutalist UI with Dark Mode**: Responsive interface tailored to brand identity, equipped with dark/light theme switching and print support.

## 🚀 Tech Stack

- **Frontend**: HTML5, CSS3 (CSS Variables & Flexbox/Grid)
- **Data Visualization**: [Chart.js](https://www.chartjs.org/), [WordCloud2.js](https://github.com/timdream/wordcloud2.js)
- **Iconography**: [Lucide Icons](https://lucide.dev/)
- **Typography**: Be Vietnam Pro, Bricolage Grotesque, JetBrains Mono
